# 任务简报模板（task brief）

派发 `spawn_agent` 时，`prompt` = 角色预设（`skill/agents/*.md`）+ 本模板的任务部分。
**规则：未填字段不出现**——只写有内容的字段，控制 prompt 体积；字段名即锚点，主 agent 照抄即可。

> **派发前先过 SKILL.md 第零步复杂度分级门**：S 级（单文件/≤2 处/无并行价值）与不委派清单命中项**禁止 spawn**，主 agent 直接做；M 级至多 1 个子任务；只有 L 级（>3 文件/可并行/需专精角色/上下文超窗）才走完整派发。子代理有固定启动/简报/汇合开销，拆了反而更慢更贵。

## 六要素速填

```markdown
## 目标
一句话可衡量的结果。示例："给 daemon_http.py 的 /agents 端点补分页，参数 limit/offset，带单测。"

## 工作范围
允许读/写的文件、目录、命令。
示例："只读 agent_mcp/*.py、tests/；可写 tests/test_daemon_http.py；可跑 pytest tests/test_daemon_http.py"

## 边界
禁止事项——不许动的文件、不许重构/提交/装包。
示例："不改 agent_mcp/daemon_http.py 之外的源码；不装新依赖；不 git commit"

## 自审级别
全量 / 轻量 / 无需。默认：读密集→轻量，写密集→全量，关键路径→强制全量；可显式覆盖。
**回传 FINAL_ANSWER 前必须自证达成**：附证据（测试输出/文件清单/自查结果）；未达成不得报完成，回传 BLOCKED。
示例："全量：实现后逐条对照验收清单自查，跑测试并贴输出；未通过不回传完成"

## 输出格式
以 FINAL_ANSWER: <摘要> 结尾，摘要 ≤3 行；长报告写文件后回传路径。
示例："FINAL_ANSWER: 分页已实现，limit/offset 生效，pytest 3 用例通过"

## 卡住升级
BLOCKED / NEEDS_CONTEXT：不瞎猜，列已尝试项与所需帮助。
示例："卡住时回传 BLOCKED: <卡点> + 已尝试 <x,y> + 需要 <z>"
```

## 字段说明与常见坑

| 字段 | 何时填 | 常见坑 |
|---|---|---|
| 目标 | 必填 | 不可衡量（"改进性能"）；写需求不写方案 |
| 工作范围 | 必填 | 范围过大导致越界；写密集任务必须列允许写的文件 |
| 边界 | 必填 | 只写"做什么"不写"不做什么"→ 子代理顺手重构/装包/提交 |
| 自审级别 | 默认规则，可覆盖 | 读密集任务要求"全量自查+跑测试"是浪费；关键路径漏了强制全量；**只报结论不附证据；未达成却报完成（子代理通病，主 agent 会按"不亲信"拒收）** |
| 输出格式 | 必填 | 不指定格式 → 回传长篇散文；忘了 FINAL_ANSWER 摘要结尾；摘要超 3 行；**无结构散文让主 agent 重读重判，烧掉委派要省的上下文——必须按角色预设的结构化形态回传** |
| 卡住升级 | 必填 | 子代理卡住后瞎猜继续；不回传 BLOCKED 导致主 agent 空等 |

## 完整示例（读密集：code-explorer）

```markdown
## 目标
摸清 agent_mcp/daemon_http.py 的 HTTP 路由与事件流，产出关键文件清单供后续规划。

## 工作范围
只读 agent_mcp/*.py；可跑 python -c 导入验证；禁止写任何文件。

## 边界
不改代码；不启动 daemon；不评估性能或安全（留给专责分支）。

## 自审级别
轻量：核对入口点/执行流/关键文件清单覆盖全部路由；不编造未读代码的结论。

## 输出格式
按角色预设的探索格式回传；FINAL_ANSWER: 路由数 + 关键文件清单 + 新开发建议摘要。

## 卡住升级
入口点不明时回传 NEEDS_CONTEXT: 已尝试 <x>，需要 <入口点线索>。
```

## 完整示例（写密集：build-error-resolver）

```markdown
## 目标
修复 pytest tests/test_daemon_http.py 的 2 个失败用例，其余用例保持通过。

## 工作范围
可读 agent_mcp/、tests/；可写 tests/test_daemon_http.py 与对应实现文件；可跑 pytest。

## 边界
最小修复：不重构、不改架构、不加新功能；不装新依赖。

## 自审级别
全量：修复后跑全量 pytest，对照"改动行 < 受影响文件 5%、无新错误引入"自查。

## 输出格式
FINAL_ANSWER: 根因 + 改动文件清单 + pytest 结果摘要（通过/失败数）。

## 卡住升级
修复超过 2 轮仍失败时回传 BLOCKED: 已尝试 <修复 A、B>，需要 <测试日志人工解读>。
```
