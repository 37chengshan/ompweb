# 工作包 C：安全、桌面与前端收尾

## 已落地

- HTTP 启动边界覆盖内部来源头并签名真实 socket IP；proxy 不信任 Host 伪装。本机 bootstrap 不再依赖 NextRequest 提供不存在的 ip 字段。
- 预加载入口与 verifier 分离，避免 bundle 导入 verifier 时重新生成签名密钥；项目命令环境不继承该内部密钥。
- Rust IPC/设备密钥使用跨平台 OS 随机源，不再在 Windows 上降级到时间戳/PID。
- 桌面端口回收要求识别独立 server.js 参数，拒绝共享 Electron 可执行文件/目录/同前缀文件名。无法读取归属时报告冲突。
- 文件树子节点使用请求代次保护；旧请求不覆盖内容、loading 或 error；卸载时失效；加载失败有可见反馈。

## Windows 验收矩阵

| 维度 | 样例 | 必须观察的结果 |
|---|---|---|
| 安装与工具链 | 新标准用户、无 Cargo、正常 npm | host 随包可执行；缺 OMP 时给出正确安装提示 |
| 安装目录 | 空格、中文、用户目录，非管理员路径 | Next/Rust/OMP/PTY 都能启动，不产生意外控制台窗口 |
| 路径 | C/D 盘、大小写、UNC、junction、长路径 | 允许路径可用；跨根与逃逸拒绝；不默默落到其他 cwd |
| 进程 | 子孙进程、卡住命令、快速关闭/重开 | 超时和关闭可完成；没有持续占用端口/文件的残留 |
| 端口冲突 | 无关 HTTP 服务占用应用端口 | 无关服务仍存活；OmpWeb 报告冲突 |
| 文件锁 | 杀毒扫描/编辑器占用、升级时 host 被占用 | 有确定错误与恢复动作，不删除未知文件或半覆盖产物 |
| 网络 | 系统代理、弱网、断网重连 | loopback 不误走代理；不出现假就绪或永久 loading |

Windows 本轮没有实机执行。GitHub Windows build 能补编译证据，不能替代上述安装与交互结果。

## App 与移动端

- packaged App 必须用候选源码重新打包；核对 app 版本与 Resources/bin host。旧安装包的历史验收不能沿用。
- 冷启动、主题、reduced-motion、关闭/重开窗口、更新后的二进制锁分别验收。
- 移动 Web 验收包含真实软键盘、SafeArea、横竖屏、输入区可达性、长消息滚动与手动上滑后的跟随状态。桌面浏览器缩小宽度不能替代软键盘实测。
- 弱网目录刷新：故意让旧响应晚于新响应，检查最新目录仍保留；错误应在对应目录内出现，不污染新路径。
- 长会话、终端标签反复创建/关闭后检查监听器、定时器和连接是否回到稳态。

## 安全回归组合

1. 真实本机 socket + 正常浏览器，首页、登录和签发配对令牌可用。
2. 非本机来源 + `Host: localhost` 或伪造内部头，没有凭证时不能绕过。
3. 密码开启时，本机来源豁免只影响配对，不能跳过密码校验。
4. 已配对设备、未配对设备、撤销设备、过期设备分别检查。
5. trusted proxy 只有在部署入口确实受信、转发头被清理时使用；不要在公开直连监听器上随意开启信任转发头。

验收过程中不撤销用户现有凭证、不替换用户安装的 App、不对无关进程执行强杀；使用隔离配置和测试程序。
